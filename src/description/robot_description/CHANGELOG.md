## v0.5.1

### Added

- 增加显式可选的 V3.2.2 解析代理描述，供闭式 IK 仿真和规划临时使用。
- 增加代理模型清单、第三放置位和装配原点隔离回归测试；默认生产入口不变。

## Unreleased

### 超声波测量坐标系（2026-11-13）

- 按用户实测安装位置加入 `ultrasonic_channel_1..8_link` 及固定关节（base_link，z=0.019 m）。
- 用户给的是"+X 向左、−Y 向前"的底盘坐标系，换算到本模型的标准 REP-103（+X 前、+Y 左）：
  `x = −Y/1000`、`y = +X/1000`，偏航按声束方向取 0 / ±π/2 / π。
- 只加测量坐标系，不建几何与惯性；三份产物同步，`compose_robot_model.py` 增加同样的一段，
  重新生成时会保留。

- 自有TCP采用J6轴线距离234.2mm和旧工具轴约定；两雷达使用用户看图确认的footprint位置，yaw=0、高度不增加15mm，仅新增测量坐标系。
- 同一运动链导出纯visual、纯collision URDF和258球＋4盒资产；旧头部20球被新H1/H2/mid360网格生成的36球替换。提供确定性生成、独立FK/GPU对拍、近似覆盖报告和三栏查看器。
- r2恢复全部GitHub关节：39 Link/25活动轴（含新增前后雷达），头部雷达随Updown/H1/H2运动，车体雷达固定；新增完整源清单与父子关系回归，GPU提供全25轴诊断。

### 六维力传感器坐标系

- 2026-11-10：按用户确认的官方作用力坐标系新增 `left_ft_sensor_link` / `right_ft_sensor_link`，以无质量固定坐标系连接各自 `tool_link`。按用户更正，以朝末端为正方向偏移 −7.2 mm：左 `xyz=[0,-0.0072,0] m`、`rpy=[-π/2,0,0]`，右 `xyz=[0,+0.0072,0] m`、`rpy=[+π/2,0,0]`。零位下两侧 +Y 向上、左 +X 向后、右 +X 向前，+Z 朝各自末端；同步模型清单、说明及运动学校验。

### 头部限位

- 2026-11-05：按用户台架实测，H1（偏航）限位改为 ±45°，H2（俯仰）改为 −40°～+35°（模型坐标）；URDF、限位 YAML、清单 `head_limits_deg`、回归测试同步。

### 双臂角度限位

- 2026-11-12：双臂 J6 限位由 ±130° 收窄为 ±110°，同步 URDF、限位 YAML、模型清单和说明。

- 2026-11-05：按用户要求，左右 J1/J3/J5/J7 改为 ±170°、J4 改为 ±145°、J6 改为 ±130°；同步 URDF、限位 YAML、模型清单和说明。J2 限位保持不变。

### 删除内容哈希

- 2026-11-05：按用户要求删除全部内容哈希：`mesh_assets.json` 的 `files` 改为路径列表；`arm_collision_import.json` 删除源/目标 URDF 与网格哈希；清单删除头部来源哈希；执行器参数删除手册哈希；测试改为核对文件存在与引用一致；导入工具不再计算哈希。来源追溯靠 git 历史与文件路径。

### MuJoCo 迁移

- 2026-11-05：将 `mujoco/`、模型转换及碰撞演示脚本迁至同级 `robot_simulation`，同步场景、网格引用和文档；MuJoCo 校验迁入仿真项目，本仓库测试仅依赖机器人描述。URDF、原始网格和动力学参数保持不变。

### 双臂速度与加速度上限

- 2026-11-04：按用户要求，左右 J1～J7 的 URDF `<limit velocity>` 与限位 YAML `max_velocity_rad_s` 统一改为 30°/s（0.5235987755982988 rad/s），限位 YAML 新增 `max_acceleration_rad_s2` = 60°/s²（速度上限的 2 倍）。执行器参数中原 `urdf_velocity_rad_s` 改名 `peak_velocity_rad_s`，数值仍为 eRob 峰值转速；清单新增 `arm_motion_limits` 记录来源。同步来源哈希与回归测试。MuJoCo 不执行速度限制，模型文件不变。

### 头部俯仰原点

### Added

- 新增 `urdf/robot_alfav3_mobile.urdf`：在已部署移动整机上把双臂替换为 Alfav3 导出模型
  （`model_sources/alfav3_arms_1011_4`，2026-10-16 SolidWorks 导出），底盘、Updown、头部和 IMU 不变。
  关节/连杆沿用 `left|right_joint1..7`、`left|right_link1..7` 命名，新增 `left|right_tool_link`（法兰件），
  `left|right_tool0` 保持原物理位姿（法兰外 151 mm）。双臂零位为 Alfav3 导出零位（即驱动 2^18 零位），
  限位按新零位对称：J1/J3/J5/J7 ±180°、J2 ±105°、J4 ±145°、J6 ±110°。视觉网格为原始导出，
  碰撞网格为 CoACD 凸分解/凸包并外扩 1 mm 的包络。新入口不提供命名姿态与初始位置，SRDF 去掉 group_state。
  这是破坏性变更：旧入口的关节空间数值不适用于新入口。
- 引入机械导出的 V3.2.2 原始模型、65 个低模网格和来源哈希；新增
  `base_footprint` 地面根，`base_link` 固定在其上方 `0.335m`。
- 增加 V3.2.2 来源与生产入口回归测试，检查单树、根坐标、17个可动关节、
  49 个实际引用网格、四套冻结姿态和吸盘/Tool0固定链。
- 集成 V3.1.1 左右七轴关节链、J1～J6 连杆资产和原始模型来源快照，
  并增加来源哈希、关键尺寸和升降方向回归测试。
- 两版共用 `active_suspension_joint` 和承载件，后侧两组舵轮支持
  `[-0.15, 0]m` 主动悬挂行程；新增 9 个主动悬挂 CAD 网格。
- 两版均集成回转/俯仰头部、五个网格及配套配置，支持 Rerun 双轴运动检查。
- 提供夹爪/吸盘两个发布分支，各自默认 Xacro、直接加载 URDF 和关节配置保持一致。

- 增加夹爪初始闭合位置、`[0, 0.080]m` 限位与资源、配置一致性回归测试。
- 集成 `robot_dual_suction.urdf` 的双吸盘末端、两个网格及对应的 16 关节配置。

- 两套末端共用四舵轮底盘 Xacro；夹爪版共 28 个可动关节，吸盘版共 26 个。
- 增加轮胎接地、立柱安装面贴合和底盘质量去重回归检查。

### Changed

- 默认生产入口切换为 V3.2.2 几何和惯量，只保留该模型实际具备的 Updown、
  双轴头部和双臂14轴；移除默认配置中的舵轮、行走轮和主动悬挂自由度。
- 将 V3.2.2 的左右 J1/J5 原始零位适配为冻结的 V3.1.1 逻辑零位，并恢复
  V3.1.1 双臂关节限位、Updown `[-1,0]m` 和四套命名姿态。
- 通过固定 ±90° 末端适配保留现有双吸盘和 Tool0，不增加运动自由度。
- 按 V3.2.2 可视化复核结果更新第一、第二放置姿态，并将拆分后的
  `link6 ↔ suction` 固定装配接触加入 SRDF 允许碰撞矩阵。
- 将 MoveIt 根语义从固定 `world → base_footprint` 更新为
  `map → base_footprint` planar virtual joint；底盘 `x/y/yaw` 只作为规划根状态，
  不增加 ros2_control 实体关节，也不改变现有 26/28 关节模型。
- Updown 保持原 1m 实体行程，坐标从中点零位重标为 `[-1, 0]m`，其中
  `0m` 是最高点；双臂通过固定适配帧接入 Kkozia 模块化上身。
- `base_footprint` 改为四轮零位轴心平均位置向下偏移 `0.1m`，不再沿用
  `[0.195, 0.015, 0.400]m` 人工安装值。
- 按 `robot_fixed_names.urdf` 将机械臂实体由 `*_jointN` 重命名为 `*_linkN`，
  保持关节名不变，并同步 J1～J7 的分级 effort/velocity 参数。
- 四套舵轮替换为主动悬挂整机导出的新网格和关节帧；前轴连接固定底板，
  后轴连接主动悬挂承载件，舵轮限位按新源更新为 `[-3.14159, 3.14159]rad`。
- 夹爪固定主体采用输入包的 `4.750 kg` 质量；吸盘末端采用 `2.618 kg` 质量，
  各自保留源文件的质心、惯量和碰撞网格偏移。
- 两套末端通过 Xacro 宏共用 Kkozia 模块化机身和 V3.1.1 双臂，并验证切换时结构一致。
- 替换旧固定底盘外形并扣除对应质量/惯量，按轮胎接地和立柱安装面贴合
  将上身整体抬高 14.2 mm；保留既有基座参考和臂关节语义。
- 按 ROS 物理左右侧交换输入包的夹爪名称，保留 Kkozia 机身坐标、
  `tool0` 坐标系和五个 SRDF 规划组。
- 用 2026-09-21 CAD 安装坐标替换旧头部相机总成，并从机械 URDF 中排除
  双目视锥和雷达视场辅助实体，避免错误碰撞体和约 23.8 kg 的虚假质量。
- 恢复 V3.1.1 右 J1/J5 原始机械零位，撤销不必要的180°逻辑重标；
  四套搬运关键帧统一采用 `right_jointN=-left_jointN` 的镜像合同。
