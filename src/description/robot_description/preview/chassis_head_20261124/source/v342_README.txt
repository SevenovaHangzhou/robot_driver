ALFA V3 整车 URDF 首版（1124）

入口文件为 urdf/alfav3_mobile_1124.urdf，网格单位为米。解压后将 alfav3_mobile_1124 保持为完整 ROS 包，以便解析 package:// 网格路径。配套 CMakeLists.txt 和 package.xml 使用 ROS 2 ament_cmake。

模型共 42 个连杆和 41 个关节。整车基准取 SolidWorks 的 base_link 坐标系（上底板中心，X 前、Y 左、Z 上）。舵轮各分转向主体和行走轮。两个后轮随主动悬挂支架一起升降，轮组安装偏移保留 CAD 位置。转向限位 ±130°，滚动连续。

上身升降关节 updown 的下限是 0 m，上限是 1.050 m。将 updown 设到 1.050 m、其余关节为 0，即回到 CAD 的高位姿态。胸口、双臂和云台随上身升降。上方朝后的 MID360 固定在车身。胸口相机和头部相机各保留左眼帧。头部相机与 head_mid360 挂 H2_Link。8 个超声波各有独立连杆，局部 +X 沿探头向外。

双臂使用 MDH 关节坐标系。右臂 7 段与左臂第一段取当前装配。左臂第 2～7 段在 URDF 中按右臂镜像生成。左臂 J6 与本地早期版本约差 24.65°，首版用当前右臂 J6 的镜像轴线。左右臂位置限位沿用指定旧查看器，速度和力矩按该查看器显示精度录入。轴向符号与本地可用的早期源文件对照，指定旧版原始 XML 尚未逐项核对。

首版供几何和运动学复核。主动悬挂保留 prismatic 关节，行程先以零占位。舵轮转向、上身升降和云台的速度及力/力矩以零占位。含曲面导入的零件有部分惯量缺失，详见 validation.json。在右臂 link4/link5 网格提取中，有 12/1 个 STEP 面未返回三角形，对应镜像 link 同样受影响。整车上下限和中点的位姿已按装配回算检查，未做实机标定、全行程碰撞或动力学验证。

arm_mdh.csv 记录 J2～J7 的 MDH 参数和矩阵回算误差。J1 的安装变换在 URDF 中单独表达。lift_limits_preview.png 对比上限与下限。validation.json 记录零件选取、位姿验证及网格检查。

V1.0 下另有 SolidWorks_PackAndGo_1124。Pack and Go 收集的是用户提供的当前装配，实际打开确认 43 个组件实例均引用包内文件。原装配备份与校验清单保存在 codex备份。
