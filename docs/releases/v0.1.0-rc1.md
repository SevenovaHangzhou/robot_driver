# v0.1.0-rc1 · 本地待验收版

日期：2026-10-30（Asia/Shanghai）。Python 包版本：`0.1.0rc1`。

本版冻结完整机器人浏览、左右臂选择与独立 Mock 姿态、TCP 三维轨迹、长按逐段 0.5 mm 点动及松键减速。包含长按卡顿和误退出修复，以及原操作台默认禁用的 UI 接入补丁。

本地交付目录：`releases/v0.1.0-rc1/`，包含源码归档、wheel、逐文件源码/外部模型哈希清单、打包复验日志和 `SHA256SUMS`。机器人 URDF/mesh 继续从原目录只读加载，不随本组件复制。校验命令：在交付目录运行 `sha256sum -c SHA256SUMS`。

自动化验证基线：组件 53 项、操作台假驱动 40 项通过；Node 输入状态机通过。浏览器已验证完整机器人、左右切换、长按/松键和 TCP 对齐，详细证据见 `docs/VALIDATION.md`。本轮将从源码归档复验组件并检查 wheel 安装；实际输出单独保存在交付目录 `validation/`。

待用户验收：

- 整机可完整观察，旋转、缩放、当前臂和 TCP 聚焦符合调试习惯。
- 左右臂切换后，高亮、坐标、当前姿态和轨迹归属正确。
- 长按方向键持续小步，松键后减速停止并保持接管；Esc、失焦后退出接管。
- 停止并退出接管后才能切换；切换后重新接管，历史轨迹不跨两侧 TCP 连线。

当前仅本地 Mock；逐段点动尚非平滑连续 Servo。TCP/水平参考系、碰撞检查、执行仲裁与故障停车仍待实机阶段验收。没有部署、使能或发送真实动作。
