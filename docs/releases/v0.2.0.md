# v0.2.0 · Mink → Rolling 键盘控制组件

日期：2026-11-09（Asia/Shanghai）；Python 包版本 `0.2.0`。

## 冻结内容

- 完整机器人、左右臂选择、实测关节反馈 FK 末端轨迹；方向以机器人本体为准。
- 0.5、1、2、5、10、20、30、50 mm/s；Mink / DAQP 生成连续未来窗口，同一 Rolling 会话追加或替换。
- 18121 与 18131 共享登录和互斥控制权，按动作入口自动选择 JTC / Rolling；现场显式使能。
- 长按续流、松手减速、再次同方向起步；停止期间保持资源占用，取消或失焦后退出接管。
- 非实时快照有界重读、98% 动态规划预算、段内约束及 C2 制动尾段；双臂碰撞与自碰撞复核。
- P50/P95/P99/最大耗时及按 epoch/sequence 匹配的关节、段号、超限值和拒绝原因。

初窗 120 ms、替换窗 100 ms。硬件包络和跟随误差阈值沿用部署 artifact，重力补偿关闭。

## 源码与取回

同一 GitHub 仓库保存两个独立源码分支：驱动集成 `codex/jog-current-framework`，外部客户端 `release/gripper-jog-v0.2.0`。客户端使用独立历史，RT-Control 构建不依赖 Mink 客户端源码。组件标签 `gripper-jog-v0.2.0` 指向客户端提交，配套标签 `jog-rolling-integration-v0.2.0` 指向驱动提交；`integration/release.json` 绑定精确驱动 SHA、公共接口 pin 和测试边界。

```bash
git clone --branch gripper-jog-v0.2.0 --single-branch git@github.com:SevenovaHangzhou/robot_driver.git gripper_end_move_handle
git clone --branch jog-rolling-integration-v0.2.0 --single-branch git@github.com:SevenovaHangzhou/robot_driver.git robot_driver_jog_current
cd gripper_end_move_handle
python3 tools/check_shared_authority.py --driver ../robot_driver_jog_current
```

本地 `releases/v0.2.0/` 保存源码压缩包、wheel、配套驱动补丁、manifest 和 SHA256SUMS；压缩包由冻结的客户端 Git 提交导出。构建产物不写入 Git。外部 real2sim 场景、Robot Model/mesh、ROS 公共接口和现场 artifact 均需单独准备，不随 Python wheel 或客户端源码复制。

推荐从源码使用 `script/start.sh`、`script/start_sim.sh` 或显式的真机入口；wheel 提供仿真 `gripper-jog` 命令，运行时须传入实际 `--real2sim` 路径。真机启动还需要已匹配的模型、接口、现场配置、受保护令牌和主操作台，按 [统一控制权](../CONTROL-AUTHORITY.md) 操作。
