# J7 坐标系下的姿态点动

18131 的真机 Mink → Rolling 入口支持位置与姿态点动。平移仍按机器人本体 `base_link` 的前后、左右、上下定义；旋转按所选机械臂 J7 转动后的局部坐标系定义。

| 正向 / 反向键 | 旋转轴 |
| --- | --- |
| Q / Z | yaw，J7 的 Z 轴 |
| W / X | pitch，J7 的 Y 轴 |
| E / C | roll，J7 的 X 轴 |

正向遵循右手定则。左臂使用当前 URDF 中 `left_joint7` 的 child frame（当前为 `left_link7`），右臂对应 `right_link7`。这里的 yaw/pitch/roll 表示局部旋转轴，不是直接增减页面上相对于 `arm_carriage` 显示的欧拉角。

旋转保持当前 TCP 位置。TCP 与 J7 原点有偏置时，Mink 同时调整选中臂的其他关节以保持 TCP 位置，不是单独给第七关节发角度。固定工具旋转偏置也参与计算。连续窗口沿首次保持姿态的单轴旋转路径推进，防止每次补窗累积横向求解误差。位置与姿态仍受求解跟踪误差影响，不能当作实机精度保证。

独立旋转速度档位为 0.5、1、2、5 °/s，默认 1 °/s。平移档位保持原来的 mm/s。页面在旋转时显示本次按住累计角度和实测角速度；角度从 J7 四元数的局部增量累计，跨 ±180° 和欧拉角奇异位姿不产生虚假的角度跳变。

只允许单个方向输入。切换平移/旋转轴或反向前先松键并等待减速完成；同一按住期间可以调整对应速度档位。自动重复按键不排队；松键减速，Esc、失焦、后台、断线或输入超时仍退出接管。18121 和 18131 共用原有双臂互斥控制权，未选中臂被冻结，保留原有 q/v/a、双臂互碰、自碰撞和整段三次曲线检查。不调用重力补偿。

接口为 `velocity` 请求 `{robot_rotation: "yaw+", rotation_frame: "j7", speed_deg_s: 1}`。旋转命令禁止同时带平移方向或 mm/s。线速度使用 m/s，角速度在后端转换为 rad/s 后交给同一条 Mink → Rolling 链路。当前旧 Mock、Mink 仿真入口未开放该功能，页面会禁用旋转按键。

验证：245 项 Python 回归通过，24 项因未提供外部测试 fixture 跳过；17 项前端单元测试通过。真实 URDF、实测关节位置、当前碰撞配置下完成左右臂六旋转方向、四档角速度共 48 个 21 点窗口离线复核。浏览器验证了双臂六键、长按重复、松键及桌面/手机布局。上述验证没有下发真机运动；首次现场验证请选 0.5 °/s，由操作者短按检查方向和 TCP 保持情况。
