# JOG-20261030 接入记录

范围：独立 Motion 侧离线组件 + RT-Control 操作台页面。运行阶段：本地 Mock；实机功能默认不可用。无 Docker、公共接口 pin、实时控制器、驱动或模型修改。

本地操作台接入只改 `server.py` 的页面/状态路由与拒绝逻辑、主页导航，并增加 `web/jog/` 资源和认证/拒绝行为测试。算法与 NumPy/SciPy 不进入 RT-Control 仓库。

浏览器本地协议：

| 接口 | 语义 |
| --- | --- |
| GET /api/jog/state?client=... | 读取状态；Mock 仅为同一页面续控制权，不续输入有效期 |
| POST /api/jog/acquire、release | 获取/释放页面控制权 |
| POST /api/jog/arm | 显式接管，返回新 epoch，锁定本次姿态 |
| POST /api/jog/heartbeat | 当前 epoch + 单调 seq 延长输入有效期 |
| POST /api/jog/step | 当前 epoch + 单调 seq、direction、speed_mm_s（0.5、1、2、5、10）；不排队。兼容旧 step_mm 接口，但不可同时传入速度与步长 |
| POST /api/jog/halt | 松键沿路径停止，作废旧 epoch，返回新 epoch；不自动产生运动 |
| POST /api/jog/stop | 任一已登录会话可停止并退出接管；即使先到达，也能阻止随后完成的规划启动 |

Mock 命令含 `client`；同 cookie 的两个页面也不能同时控制。运动与保活分别使用独立序号，各自在一个 epoch 内递增，失败不得自动重放；响应不明时读取状态或停止。新页面/重连/重启不能继承旧 epoch。服务独立检查输入有效期，不以网页轮询仍在线证明允许继续运动。

**以上接口不构成实机公共契约。** 真实操作台目前只提供 `/jog` 与认证状态读取，并统一拒绝点动命令。不得将 Mock 服务反向代理到实机并宣称接入完成。

制动：保持原样条路径，拟合满足起始位置/速度/加速度/jerk 以及终点零速度/加速度/jerk 的时间曲线，检查单调性和动态限制。若找不到更短的有效曲线，执行剩余的有限自然减速段；因此“停止请求已收到”不等于已停稳。该实现只在 Mock 中执行，实机制动仍需执行器与故障链合同。
