## 背景

承接 [机械参数核对](2026-09-24-electri-136-mechanical-inertia-review.md)：同批左右网格遵循
Rz(π) 装配关系，人工质心则采用 y 反射。用户确认第一版只实现机械臂和夹爪自重补偿，
工件负载更新暂不实现；带载提起/卸载仍属于后续实机验收范围。本轮量化上述质心解释差异，
不裁决机械参数，不扩大为代码接线或实机操作。

## 改动

无模型、源码、配置或厂商参数修改。新增本记录和索引；只在离线计算内构造条件性 COM 变化。
一次性计算脚本及 JSON 数值证据位于控制工作区忽略目录
`.runtime/audits/ELECTRI-136-20260924/` 的 `com_gravity_sensitivity.py`、
`com-gravity-sensitivity.json` 和 `com-gravity-cross-check.json`。

对比定义：

- A：机械导出的原始右臂参数。
- B：假设左侧质量属性是参考、对应左右部件内部质量分布相同，将左侧 CAD COM 按
  `p_R=diag(-1,-1,1)*p_L+[880,0,0]mm` 换算到右侧。B 只是敏感性候选，不是批准的修正模型。
- 用源 URDF 零位 FK 将 CAD COM 差向量转换到各右侧 link 的局部坐标，运动时随所属 link 旋转；
  不把 CAD 差向量固定在世界坐标中。
- 两个候选保持相同质量、运动学、关节方向及 link 归属，唯一差异是右侧 COM。
  本轮不修改惯量张量，因为静态重力项不依赖绕质心转动惯量。
- 离线场景重力明确设为候选 CAD/base 坐标下 `[0,0,-9.81]m/s²`，不是本机安装标定裁决。
  包含七连杆及 hand，不含外部工件，升降锁定零位，活动夹爪默认锁定零位。
- 在候选导出自带的 7 轴 `[-1.57,1.57]rad` 范围内随机取 20,000 组 q，seed=20260924。
  此范围此前已发现与当前公共模型不一致；采样未做碰撞检查，不代表实机可执行姿态。

## 验证

输入哈希在脚本启动时核对：

| 文件 | SHA-256 |
| --- | --- |
| `robot.urdf` | `abdabe00eb1f79761fbe5603c4dff5e6b473e2f9429c36d0e436c9ed3f60942e` |
| `user_model.json` | `ff535be98bf35aca993656211668d6e8a820e1b6c9350730191d7b6fc546fbc6` |

执行：

```text
PYTHONNOUSERSITE=1 python3 <审查目录>/com_gravity_sensitivity.py <导出目录> <结果JSON>
```

以 SI 单位计算保持力矩：

```text
G_i = -a_i · Σ下游 [ (c_k-o_i) × (m_k*g_world) ]
ΔG_i = G_B,i - G_A,i
```

其中 a_i 是世界坐标关节单位轴，o_i 是轴上原点，c_k 是世界坐标质心。
本计算没有调用 Pinocchio，使用 FK 与重力矩投影，并用独立方法交叉核对。

右臂结果（N·m，关节名称/正方向均按候选导出）：

| 轴 | 20,000 姿态采样最大绝对差 | 该 COM 差的保守全姿态上界 | 候选零位 G_A | 候选零位 G_B |
| --- | ---: | ---: | ---: | ---: |
| J1 | 5.48065 | 5.93367 | -2.06942 | +2.06942 |
| J2 | 1.24377 | 1.85107 | -175.09405 | -175.09405 |
| J3 | 1.27645 | 1.54534 | -0.33810 | -0.43806 |
| J4 | 0.97869 | 1.21994 | +0.00705 | +0.11805 |
| J5 | 0.85497 | 1.09056 | +0.10139 | -0.43786 |
| J6 | 0.77243 | 0.87411 | -0.06941 | +0.13111 |
| J7 | 0.82433 | 0.82441 | +0.30944 | -0.48688 |

各行的采样最大值不一定出现在同一姿态，不能把它们拼成一个实际关节力矩向量。
零位为这份机械导出的 q=0，不是当前实机零位、默认启动姿态或已验收公共模型零位。
G_A 与 G_B 符号不同仅说明两种假设给出相反方向，不证明哪一个符合实物。
重力接近零的轴不使用百分比误差，避免把小分母放大成误导结论。

解析上界：旋转关节重力差满足

```text
|ΔG_i| ≤ 9.81 * Σ下游 (m_k * ||Δc_k||)
```

该上界对这里构造的 COM 差成立，不依赖随机采样覆盖度，允许不同 link 的贡献保守同向叠加。
它不是“真实机器人所有模型错误均小于此值”的保证，也不覆盖动态项、质量漏计或轴线错误。

- link1 单项：`11.831kg × 9.81m/s² × 0.035176m ≈ 4.08260N·m`，是主要差异来源。
- link7 单项上界约 0.77175N·m；hand 虽偏移约 62.422mm，但本批质量只有 0.086kg，
  单项上界约 0.05266N·m。因此 COM 偏移距离大不一定意味着最大力矩影响。
- 各轴采样差均小于解析上界；夹爪固定在 0 与 0.09m 时复核，COM 差导致的 ΔG 相同。
  此结果仅针对相同平移关节位移下的两种 COM 参数比较，不代表夹爪开度不改变绝对重力力矩。

独立交叉验证：

1. 对 16 组姿态用中心差分（步长 1e-6rad）计算重力势能梯度，对照上述力矩投影。

3. 从原始 JSON 独立计算 J1 的 `m*g*||Δc||` 求和，得到 `5.9336696352 N·m`，
   与主脚本一致，PASS。

## 结论与冻结事实

- F1: 在本记录明确的条件假设下，左右 COM 装配解释差异产生最高约 5.48N·m 的采样差，
  对应 J1 保守上界约 5.94N·m；腕部 J7 约 0.82N·m。它不是纯文本舍入误差。
- F2: 一些候选姿态的重力补偿方向因 COM 解释不同而改变。仍须机械方提供两侧独立质量属性，
  不能选择其中一套直接发布，BQ-152 保持开放。
- F3: 第一版纯重力项不依赖绕质心的转动惯量；当前优先核实质量、COM 和运动学。
  本记录没有量化动态惯量错误，也没有证明其他机械参数正确。
